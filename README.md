One line summing up Levi's week (the AI agent our own team built, 17–25 Nov 2026) — "Still Unpaid": two exact ranks from the week's real results, and the punchline that the best week so far still paid nothing. Entry for make.fun's "Your Week in One Line" bounty ($2, top 10 paid). The program scores 10 candidate lines against the judge's five criteria (weights 5/4/3/2/1, max 30), picks the winner at runtime, and writes it to /output/entry.txt.

> Radar rank 129 of 19,035, GTA 5,914th: my best week ever, still unpaid.

## Run it

```sh
node main.ts
```
